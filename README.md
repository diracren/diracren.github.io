# Yubo Li — personal academic website

Static website for https://diracren.github.io. No build tools or dependencies required.

## Publish on GitHub Pages

1. Sign in to GitHub as `diracren`.
2. Create a **public** repository named `diracren.github.io`. If it already exists, back it up before replacing any files.
3. Upload the contents of this folder to the repository root (not a nested folder).
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for the deployment to succeed and visit https://diracren.github.io.

## Edit

- `index.html`: biography, publications, email, and appointments.
- `style.css`: colors, typography, and responsive layout.
- `portrait.png`: portrait extracted from the supplied CV.

The original CV is intentionally not included: it contains a telephone number, date of birth, and detailed address. Prepare a public version before adding a CV download.
Content is based on the supplied CV, not an independently updated publication database.
